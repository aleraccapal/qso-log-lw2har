Instalación

Para instalar la aplicación en la pantalla de inicio, abrila desde una dirección HTTPS, por ejemplo después de publicarla como sitio estático. La primera apertura debe hacerse con Internet para que el navegador guarde la aplicación en caché. El registro funcionará sin Internet después de esa primera carga.

Importante: si borrás los datos del navegador o cambiás de dispositivo, podés perder los QSO no respaldados. Descargá la copia JSON periódicamente. La exportación ADIF es útil para otros libros de guardia, pero no incluye toda la estructura editable de las ruedas.
